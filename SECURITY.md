# Security policy

Report vulnerabilities in private. Do not open a public issue for a security report.

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x on `main` | Yes |
| Older tags | No |

This project ships Windows x64 builds only.

## How to report

1. Open a [private vulnerability report](https://github.com/Columbia-Cloudworks-LLC/DataMan/security/advisories/new) on this repository.
2. Include the affected version or commit, the impact, and steps to reproduce.
3. Wait for a maintainer to reply before you disclose the issue in public.

If GitHub private reporting is unavailable, contact a [Columbia Cloudworks LLC](https://github.com/Columbia-Cloudworks-LLC) owner through GitHub.

## What we will do

A maintainer will acknowledge the report and say whether we can reproduce it. Fixes ship on `main` and go out in the next GitHub Release zip.
